Tornando Páginas Web Interativas com JavaScript

Incluindo JavaScript

Existem múltiplas maneiras de incluir JavaScript em uma página web. É altamente recomendado utilizar uma estrutura de diretórios organizada, separando arquivlos CSS em uma pasta e arquivos JavaScript em outra, geralmente chamada de scripts. O código JavaScript pode ser armazenado em arquivos externos com a extensão .js e integrado ao HTML por meio do elemento script, usando o atributo src para indicar a fonte. Ainda que seja possível definir o código JavaScript dentro do elemento script no HTML, essa prática não é recomendável por misturar linguagens em um único arquivo.

Exibindo Caixas de Diálogo

JavaScript oferece funções nativas para a exibição de caixas de diálogo: alert() para mensagens simples, confirm() para diálogos de confirmação com os botões de OK e Cancelar e prompt() para caixas que recebem entradas de texto. Na prática, contudo, essas ferramentas são pouco usadas por serem limitadas em funcionalidade não serem costumizáveis.

Tipo Funcionalidade Teste
alert() Exibe uma caixa simples de diálogo.
confirm() Exibe uma caixa de diálogo com os botões "OK" e "Cancelar".
prompt() Exibe uma caixa de diálogo com um espaço para entrada de texto.

Usando o Console de Desenvolvedor

Para fins de teste, os navegadores oferecem consoles de desenvolvedor onde mensagens podem ser escritas a partir de programas JavaScript. Por meio do objeto console, desenvolvedores podem usar alguns métodos, como mostrados na tabela a seguir:

Método Funcionalidade
.log() Mensagens normais.
.debug() Depuração.
.error() Mensagens de erro.
.info() Informações.
.warn() Avisos.

Variáveis, Constantes, Tipos de Dados e Operadores

Definindo Variáveis

As variáveis são contâiners para armazenar dados que podem mudar durante a execução. Em JavaScript moderno, usa-se a palavra reservada let para declarar uma variável, seguida da atribuição de um valor, que podem ou não ser feitos na mesma linha.

Definindo Constantes

Constantes são inicializadas uma vez e o seu valor não pode ser alterado depois. Elas são definidas pela palavra reservado const. Por convenção, seus nomes são escritos em caixa alta.

Usando Tipos de Dados

JavaScript possui um total de 6 tipos de dados, contudo, os tipos especiais não serão explicados. A tabela abaixo explica cada um deles:

Tipo de Dado Descrição
Números Usado para realizar cálculos matemáticos, contagens e definir intervalos.
Strings Usadas quando se trabalha com textos de qualquer tipo.
Booleanos Valores que representam apenas dois estados (verdadeiro e falso).
Objetos Usados para agrupar informações de forma significativa e organizada.

Usando Estruturas de Controle

Usando Instruções Condicionais e Ramificações

As estruturas de controle definem quantas vezes um bloco de código deve ser exectutado ou se ele deve ser executado.

Estrutura de Controle Função
if\else Executra um bloco se uma condição for verdadeira. Junto com o else, adiciona caminhos alternativos.
switch\case Permite ramificações baseadas em valores específicos de uma variável.

Usando Repetições

As estruturas de repetição executam um bloco de código enquanto uma condição for atendida.

Estrutura de Repetição Função
for Utiliza uma variável de contagem, uma condição de parada e uma expressão de incremento.
while Verifica a condição antes de cada iteração, podendo nem chegar a executar o bloco de código.
do\while Verifica a condição após a iteração, garantindo que o o bloco de código seja executado pelo menos uma vez.

Funções e Tratamento de Erros

Definindo e Chamando Funções

Funções agrupam código em blocos reutilizáveis. Elas podem ser criadas via declaração de função (com a palavra reservada function), expressões de função (atrubuindo uma função anônima a uma variável) ou arrow functions.

Passando e Analisando Parâmetros

Valores podem ser passados para as funções através de parâmetros, definidos entre parênteses, permitindo que o código em questão opere sobre valores dinâmicos.

Definindo Valores de Retorno

As funções podem devolver informações para o código que a chamou usando a palavra reservada return.

Tratamento de Erros

Existem três tipos de erro: erros de sintaxe, de execução e lógicos. Os erros de execução podem ser tratados com blocos try\catch. O código que pode gerar o ero é colocado no try, e a execução passa para o tcatch, onde deve ser tratado. É possível também disparar erros manualmente usando a palavra reservada throw.

Objetos e Arrays

Usando Objetos

Os objetos agrupam funcionalidades relacionadas. A forma mais simples de criá-los é a notação {}, onde se definem as propriedades e métodos. O acesso aos membros de um objeto é feito por meio da notação objeto.membro. Na criação de um objeto, a palavra reservada this é usada para referenciar o próprio objeto dentro de seus métodos.

Usando Arrays

Os arrays agrupam valores. Eles podem ser criados com colchetes e os elementos dentro deles separados por vírgulas. O acesso dos itens é feito por meio de seus índices. Alguns dos métodos dos arrays são push(), pop(), filter(), map() e forEach(). Loops são também usados para iterar sobre arrays e a propriedade length é usada para obter seu tamanho.
