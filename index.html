Tornando Páginas Web Interativas com JavaScript

Incluindo JavaScript

Existem múltiplas maneiras de incluir JavaScript em uma página web. É altamente recomendado utilizar uma estrutura de diretórios organizada, separando arquivlos CSS em uma pasta e arquivos JavaScript em outra, geralmente chamada de scripts. O código JavaScript pode ser armazenado em arquivos externos com a extensão .js e integrado ao HTML por meio do elemento script, usando o atributo src para indicar a fonte. Ainda que seja possível definir o código JavaScript dentro do elemento script no HTML, essa prática não é recomendável por misturar linguagens em um único arquivo.

Exibindo Caixas de Diálogo

JavaScript oferece funções nativas para a exibição de caixas de diálogo: alert() para mensagens simples, confirm() para diálogos de confirmação com os botões de OK e Cancelar e prompt() para caixas que recebem entradas de texto. Na prática, contudo, essas ferramentas são pouco usadas por serem limitadas em funcionalidade não serem costumizáveis.

Tipos de Caixas de Diálogo
alert() Exibe uma caixa simples de diálogo.
confirm() Exibe uma caixa de diálogo com os botões "OK" e "Cancelar".
prompt() Exibe uma caixa de diálogo com um espaço para entrada de texto.

Usando o Console de Desenvolvedor

Para fins de teste, os navegadores oferecem consoles de desenvolvedor onde mensagens podem ser escritas a partir de programas JavaScript. Por meio do objeto console, desenvolvedores podem usar alguns métodos, como mostrados na tabela a seguir:

Métodos Comuns do Objeto console
.log() Mensagens normais.
.debug() Depuração.
.error() Mensagens de erro.
.info() Informações.
.warn() Avisos.

Variáveis, Constantes, Tipos de Dados e Operadores

Definindo Variáveis

As variáveis são contâiners para armazenar dados que podem mudar durante a execução. Em JavaScript moderno, usa-se a palavra reservada let para declarar uma variável, seguida da atribuição de um valor, que podem ou não ser feitos na mesma linha.

Definindo Constantes

Constantes são inicializadas uma vez e o seu valor não pode ser alterado depois. Elas são definidas pela palavra reservado const. Por convenção, seus nomes são escritos em caixa alta.

Usando Tipos de Dados

JavaScript possui um total de 6 tipos de dados, contudo, os tipos especiais não serão explicados. A tabela abaixo explica cada um deles:

Tipos de Dados em JavaScript
Números Usado para realizar cálculos matemáticos, contagens e definir intervalos.
Strings Usadas quando se trabalha com textos de qualquer tipo.
Booleanos Valores que representam apenas dois estados (verdadeiro e falso).
Objetos Usados para agrupar informações de forma significativa e organizada.
